# 胡萝卜大盗 · 高清素材

使用内置 imagegen 生成的原创素材，2026-10-26。

- `garden-hd.png`：以已确认的效果稿为风格参考生成，不含角色、计分牌及操作提示，供 Canvas 渲染。
- `rabbits-hd.png`：透明背景双角色图集，奶油兔与灰灰兔，运行时分区绘制。

场景提示词摘要：细腻像素田园、蓝天远山湖泊、果园、雏菊与兔子洞，连续地面和三个草顶跳台，无 UI、文字与角色。
角色提示词摘要：同尺寸朝右的奶油白兔与蓝灰兔，橙色及鼠尾草绿领巾、编织背包，精细像素插画，透明图集。

图集使用 Canvas 裁切绘制；界面、计分和碰撞独立运行。高清画布为 2240 × 1040，游戏逻辑坐标为 1120 × 520。

## 连续关节动画

`rabbits-rig.png` 使用内置 imagegen 生成，提示词为同一兔子角色的透明分层动作素材：两行三列，分别为身体与头耳、前肢、后腿，保留奶油兔橙领巾与灰兔绿领巾。运行时按 alpha 边界取样，肢体以连续角度摆动，起停及转身平滑过渡。静态场景由 CSS 合成，避免每帧重绘高清背景。

## 游戏内运动节奏

兔子的移动使用按路程推进的成对小蹦，停止后平滑恢复站姿。腾空时停止地面循环，按竖直速度收腿和伸爪；短跳、负重跳跃沿用真实物理节奏。地面与跳台落地均触发短暂压缩。动作预览页保留为独立拆解示意。

## 五关合作冒险

- `world-map.png`：五地区连续世界地图，内置 imagegen 生成；交互节点、解锁状态与路径由网页叠加。
- `campaign-scenes.png`：五行等高的背景图集，依次为晴天菜园、风车山坡、金色果园、青绿森林、暮色营地。内置 imagegen 生成，参考已确认的 `design/five-level-ui.png` 与原有 `garden-hd.png`。运行时分行取样，平台、角色、投刀、强盗和收集物由游戏独立绘制。

提示词摘要：细腻像素田园、连续地面与两侧安全兔洞、五种逐步变化的环境，不含 UI、文字、角色或浮空平台；地图使用俯视连续地理、道路连接五个地区，不含编号或按钮。背景装饰不参与碰撞。

玩法配置见 `campaign.js`：共同目标 15 / 20 / 25 / 30 / 40 根，时限 120 / 115 / 110 / 105 / 100 秒。第三关引入投刀，第四关引入一名偷菜强盗，第五关组合投刀与两名强盗。当前浏览器 localStorage 保存通关进度，原双人抢菜对战保留。

运行检查：`node tests/campaign.test.cjs`。本地预览：在本目录执行 `python3 -m http.server 8765`。

## 强盗与空投

第四、五关强盗使用重力和单向平台碰撞，主动跳上高台追逐背菜玩家，也能穿过当前平台下台巡逻；踩晕持续 2.5 秒并掉出偷走的收获。第三关起每约 4—8 秒随机空投：加速靴（8 秒、移动速度 1.5 倍）、双倍工具（8 秒、每根收菜计 2 根，背包上限仍为 8）或炸弹。相同工具刷新持续时间，两种效果可以同时生效。空投先显示提示，炸弹落地闪烁 1.1 秒后爆炸，85 像素范围内扣背包最多 4 根，存入兔洞的收获保留，无敌期保护有效。换关、重试会清除所有空投和增益，对战模式不启用。图形由 Canvas 绘制。

`tests/preview.html` 是第五关视觉验证页面，仅内存中放置工具与敌人，不保存解锁进度。

## 开场与收尾

`presentation.js` / `presentation.css` 使用现有田园和角色素材组成首页、双兔轻跳、2.2 秒关卡入场（重试 0.85 秒）、首次机制提示、1.2 秒通关庆祝与独立结算。入场期间不推进游戏倒计时、敌人或道具，Space / Esc / 跳过按钮可立即进入。第五关结算增加兔洞窗灯、粮仓与双兔回家场景。失败页展示未完成数量和对应建议，结算页显示两人入库贡献、用时及最佳纪录。`carrot-heist-presentation` 单独保存最佳纪录与已见提示，兼容原通关存档。页面响应系统减少动画偏好；音效延续静音开关。`tests/story-preview.html` 提供结局、失败和入场验证，存档写入已禁用。
